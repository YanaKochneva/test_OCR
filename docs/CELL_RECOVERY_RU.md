# Восстановление пропущенного текста ячеек

Основной движок остаётся Docling / PP-OCRv5. Эталонный DOCX используется только для оценки результата, не для распознавания или подстановки текста.

## Изменения

1. Повторное чтение внутри ячейки может добавлять длинные пропущенные фрагменты. Для точного дополнения прежние слова и знаки должны сохраниться в прежнем порядке.
2. Для вариантов с исправлением символов применяется минимальное сходство 0,7, ограничение длины и прежняя проверка удаления токенов. Это порог сходства текстов, а не снижение порога уверенности OCR. Прежний порог 0,8 отклонял некоторые полные варианты именно из-за большого объёма восстановленного текста.
3. Уже распознанные числа должны присутствовать в новом варианте в исходном порядке. Спорные числовые коррекции автоматически не принимаются.
4. Если обычный проход не дал допустимого текста, выполняется резервное обнаружение строк внутри кропа ячейки. Принимаются строки с уверенностью не ниже 0,9, находящиеся внутри кропа. Максимум 20 попыток на страницу.
5. После изменения ячеек сбрасывается устаревшее представление таблицы HTML; экспорт строится из актуальных ячеек.

Резервный проход включён по умолчанию. Отключение для измерения скорости: `$env:DOCPIPE_OCR_CELL_DETECTION_RECOVERY = '0'`, затем перезапуск приложения. Основной режим в интерфейсе — Docling — PP-OCRv5.

Отдельная экспериментальная проверка смешанных слов через латинскую модель доступна как `DOCPIPE_OCR_LATIN_RECHECK=1`. На проверенных кропах страницы 9 документов 3 и 4 она не изменила результат, поэтому по умолчанию выключена.

## Ограничения

Дополнительные проходы увеличивают время обработки. Высокая уверенность OCR не гарантирует правильности символов. Пустые или отсутствующие ячейки и частично прочитанные ячейки — разные случаи: этот этап работает с существующими ячейками, а не достраивает отсутствующую структуру таблицы. Полнота исходного текста и визуальная идентичность требуют отдельной оценки.

Полные измерения сохраняются в `reports/benchmark-cell-completion-003-004-20261012`; сравнение изменённых ячеек — `cell-changes.json`.
