## Ограничения качества

- На странице 2 сохранённого OCR практически отсутствуют строки содержания.
  Экспорт не может восстановить текст, который не попал в результат OCR.
- Применяется общий набор размеров шрифта по типу блока; исходные размеры,
  начертания и параметры абзацев не представлены полноценно в IR.
  Полное совпадение стиля с эталонным DOCX пока не подтверждено.
- Увеличение высоты таблицы может сдвинуть следующие объекты. Для других
  документов необходима дополнительная проверка выхода за границы страницы.

## Веб-интерфейс

Поле ключа и отправка `X-API-Key` удалены. По умолчанию обработка доступна
без ключа, даже если сохранилась старая переменная `DOCPIPE_API__API_KEY`.
Обязательная авторизация отдельного API включается только через
`DOCPIPE_API__REQUIRE_API_KEY=true`. Docker Compose больше не требует ключ
для запуска.
