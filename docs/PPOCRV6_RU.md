# Локальный распознаватель PP-OCRv6 Medium RU

Основной распознаватель Docling и повторное чтение строк используют ONNX-экспорт русской модели автора:

- Paddle: https://huggingface.co/vladlinv/PP-OCRv6_medium_rec_ru
- ONNX: https://huggingface.co/vladlinv/PP-OCRv6_medium_rec_ru_onnx
- Зафиксированная версия ONNX: `dff15ea4a253e702786597894b1d36fa8bfed7b1`.

Явная установка из корня проекта: `python scripts/download_russian_recognition.py`.
Для внешней папки задайте `DOCPIPE_RU_REC_MODEL_DIR`: в ней должны находиться `model.onnx` и `rec_keys.txt`. Скачивание выполняется только отдельной командой; распознавание работает с локальными файлами и не отправляет документы наружу. Отсутствие файлов приводит к ошибке, а не незаметному возврату к старой модели.

Словарь берётся из того же репозитория. Размер входа — 3×48×640 с динамической шириной. Применён рекомендованный автором padding: минимальная ширина 640, для длинных строк — коэффициент 1.5. Он применяется как к основному читателю Docling, так и к повторному чтению строк. Настройка выполняется на экземпляре читателя, без изменения установленного RapidOCR.

Детектор PP-OCRv5 и разметка Docling сохранены. Дополнительные независимые ESLAV/Latin-модели остаются для проверки неоднозначных фрагментов; старый Cyrillic PP-OCRv5 больше не используется. Число CPU-потоков ONNX по умолчанию 4, меняется через `DOCPIPE_OCR_THREADS`.

Контрольные суммы скачанных файлов сохраняются в локальном `manifest.json`. Веса исключены из Git. Эта замена сама по себе не подтверждает улучшение CER/WER: метрики должны вычисляться отдельным прогоном.
