# Состояние проекта после очистки

13 октября 2026 года. Есть основной OCR-маршрут Docling / PP-OCRv5, локальный
интерфейс, очередь заданий, CLI, восстановление таблиц и изображений, экспорт и оценка качества.

Последний подтверждённый средний CER на документах 3 и 4 — 5,8024%.
Цель 3% не достигнута; числа сохранены в `QUALITY_BASELINE_RU.md`.
Полное совпадение оформления и отсутствие всех ошибок OCR не гарантированы.
Автоматическая проверка не заменяет визуальную приёмку результата.

Тестовые наборы и результаты удалены по запросу. CI оставлен для статических
проверок; unit/e2e-тестов в очищенном проекте нет. Новый OCR-прогон и сборка
Docker при очистке не выполнялись. Для промышленной готовности нужны независимые
проверки качества, нагрузки, безопасности и развёртывания.

Основной запуск — локальное окружение. Docker-файлы сохранены как варианты
развёртывания; это не подтверждение работоспособности всех контейнерных сценариев.
GLM и альтернативные движки включаются явно и не требуются основному маршруту.
