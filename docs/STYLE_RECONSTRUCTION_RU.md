# Восстановление оформления по скану

Обработка локальная. Исходные страницы не используются как фон. В PDF
создаются видимые текстовые объекты; DOCX сохраняет редактируемые текстовые
области и нативные таблицы. Отдельные изображения остаются отдельными файлами.

Гарнитура не закрепляется за компанией или тестовым набором. Сервис обнаруживает
TTF-файлы в системных каталогах и каталоге fonts пакета, читает названия семейств
и начертаний из файлов. Дополнительные каталоги задаются DOCPIPE_FONT_DIRS,
разделитель — системный os.pathsep (точка с запятой на Windows).

Для сравнения используются изображение букв, толщина штрихов, локальные слова
и контекст соседних строк. Пробелы выравнивания не считаются формой шрифта.
Результат хранит гарнитуру, размер, жирность, курсив, положение базовой линии,
оценку несовпадения и отрыв от следующего кандидата. Смешанные начертания
сохраняются по словам, когда их границы однозначны. Цвет и толщина правил
таблиц оцениваются по нейтральным длинным линиям; цвет заливки — отдельно.

Чтение фрагментов для восстановления переносов не заменяет распознанный текст:
последовательность исходных слов сохраняется. Эталонные DOCX не передаются
в распознавание или подбор шрифтов. Они используются только для оценки.

## Предварительный результат

По согласованной бизнес-логике неоднозначные области отмечаются, а файл
выдаётся как предварительный. PDF содержит аннотации Highlight, DOCX —
комментарии, style-review.json — страницы, рамки и причины. API возвращает
review_required, интерфейс показывает «Предварительный документ готов».
Проверка typography_review возвращает WARN, не подтверждение точного оформления.

Текущие эвристики направляют на проверку при отрыве кандидатов меньше 0,004
или оценке несовпадения больше 0,08. Это пороги предварительного отбора, а не
измеренная точность классификации. Отсутствие пометки не доказывает идентичность.
Недоступная гарнитура, ошибки букв и нетипичные смешанные стили также требуют
проверки. CFF/OTF и TTC пока не участвуют в инвентаризации; доступные TTF-файлы
не заменяют неизвестную исходную гарнитуру с подтверждением точности.

Политика оценки CER остаётся отдельной: reference_scoped исключает вставки
только при сравнении с эталоном. Обычный CER сохраняется. Пометки оформления
не меняют текст и не улучшают CER искусственно.
